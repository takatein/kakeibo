# Receipt Parser Agent（設計書 §8-2）

## 役割
レシート画像から支出情報を抽出する。

## 使用モデル
Amazon Nova Pro（マルチモーダル対応）

## 入力
- S3に保存されたレシート画像のキー
- または Base64 エンコードされた画像データ

## 出力フォーマット

```json
{
  "items": [
    {
      "shopName": "イオン品川シーサイド店",
      "amount": 3580,
      "date": "2026-02-20",
      "category": "food_home",
      "memo": "食料品まとめ買い",
      "confidence": 0.92,
      "lineItems": [
        { "name": "牛乳", "amount": 248 },
        { "name": "豚バラ", "amount": 580 },
        { "name": "野菜セット", "amount": 398 }
      ]
    }
  ],
  "rawText": "（OCR結果テキスト）"
}
```

## 抽出ルール

### 店名
- ヘッダー部分から店名を抽出
- チェーン店は正式名称に正規化（例: マクド → マクドナルド）

### 金額
- 合計金額を優先
- 税込み・税抜きの判定
- 割引・クーポン適用後の実支払額

### 日付
- レシートの日付を YYYY-MM-DD 形式に変換
- 和暦対応（令和 → 西暦）

### カテゴリ推定
- 店名からの推定（スーパー → food_home）
- 品目からの推定（医薬品 → medical）
- 金額からの推定（飲食で3,000円以上 → food_premium）

## プロンプトテンプレート

```
あなたはレシート画像を解析するAIです。
画像からすべての支出情報を正確に抽出してください。

## 抽出項目
1. 店名（ヘッダーから）
2. 日付（YYYY-MM-DD形式）
3. 合計金額（税込み）
4. 個別品目（名前と金額）

## カテゴリ分類ルール
- スーパー・生鮮食品 → food_home
- ファミレス・ファストフード → food_restaurant
- 3,000円以上の飲食 → food_premium
- ドラッグストア → daily_goods
- 病院・薬局（処方箋） → medical

## 出力
JSON形式のみ返してください。
```

## エラーハンドリング
- 画像が不鮮明: confidence < 0.3 で返却、clarification を付加
- OCR 失敗: E1001 エラーコード
- 金額が読み取れない: amount = 0, confidence = 0.1 で返却
